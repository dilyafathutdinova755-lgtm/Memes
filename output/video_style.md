# Стиль генерации видео «ЕГЭ Тренажёр» (на будущее)

Параметры для фото-части (0–6 сек), поверх основного ТЗ из `ЕГЭ Тренажёр формат видео ТЗ.pdf`:

- **line_spacing (интервал между строк): 4px** — было 12–14, сделано теснее по просьбе
- **shadowcolor: black@0.25** — было 0.18, тень усилена до 25% непрозрачности
- **shadowx/shadowy: 3**
- **fontcolor:** white, **text_align:** C+M (центр по обеим осям)
- **fontfile:** /usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf
- **fontsize:** подбирается так, чтобы хук помещался в ≤4 строки при ширине ≤920px (обычно 64, для длинных хуков — меньше, напр. 48)
- **alpha (fade-in):** `if(lt(t,0.5),0,if(lt(t,0.9),(t-0.5)/0.4,1))` — появление с 0.5 по 0.9 сек

## Фикс дрожания (jitter) при zoompan

Проблема: если применять `zoompan` сразу на кадре 1080×1920, он считает крop-окно в целых пикселях этого маленького разрешения — шаг зума в 1px даёт заметный скачок/тряску, особенно в начале ролика (зум около 1.0).

Фикс — перед `zoompan` кадр дополнительно апскейлится в 4 раза (lanczos), чтобы у zoompan был запас в пикселях для плавного дробного зума:

```
scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,
scale=4320:7680:flags=lanczos,
zoompan=z='1+0.08*on/359':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=360:s=1080x1920:fps=60,
...
```

Также вход с фото задаётся как `-loop 1 -framerate 60 -i photo.jpg` (явный framerate 60, а не дефолтный), чтобы кадры на входе в zoompan шли ровно, без рваного даплицирования.
