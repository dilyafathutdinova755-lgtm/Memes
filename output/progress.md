## Музыка (с видео 14, правило постоянное)

Пользователь прислал 5 аудиодорожек (извлечены из скринкастов, лежат в
`output/audio/track1..5.m4a`, AAC 44.1kHz stereo). Правило действует для
всех видео начиная с №14 и **остаётся в силе для всех будущих партий**,
пока не будет сказано иначе:

- На каждое видео случайно (с повторами) выбирается один из 5 треков.
- Трек **полностью заменяет** родной звук ролика (100% громкость, без подмешивания).
- Итоговая длительность ролика = **min(длительность видео ~15.02с, длительность трека)**:
  - трек короче видео → обрезается видео (конец аутро укорачивается)
  - трек длиннее видео → обрезается сам трек

Длительности треков: track1=13.93с, track2=14.30с, track3=14.51с, track4=14.90с, track5=16.13с.

## Автоматизация: ежедневная генерация в 7:00 (Europe/Moscow)

С 27.08.2026 настроен ежедневный автозапуск (cron `0 4 * * *` UTC = 7:00 МСК),
каждый день генерирует **40 новых видео** без участия пользователя. Правила
для автономного прогона:

1. **Пары (фото+хук):** брать следующие 40 свободных номеров подряд от
   текущего указателя ниже.
2. **Хуки:** сначала ХУКИ.pdf (1–100), затем `100 хуков ЕГЭ Тренажёр 101-200.pdf`
   (добавлен 27.08.2026, хуки 101–200) — итого 200 доступно. **Когда все
   доступные хуки заканчиваются — начинать заново с хука №1** (по кругу, как
   и фото), а не останавливаться. Пара «фото+хук» всё равно уникальна по
   номеру, даже если и фото, и хук в моменте повторяются.
3. **Фото:** по кругу из отсортированного списка `IMG_*.jpeg` в корне репо.
   С 27.08.2026 добавлены IMG_4013–4032 (20 штук) — теперь в пуле **56 фото**
   (было 36). Пары 1–53 уже использовали старый цикл из 36 (см. таблицу);
   начиная с пары 54 цикл идёт по всем 56 (позиция = ((номер_пары−1) mod 56) + 1
   по отсортированному списку файлов).
4. **Музыка:** правило то же, что и раньше (см. раздел выше) — трек случайно
   из `output/audio/track*.m4a` (включая любые новые, если добавлены),
   полная замена звука на 100%, длительность = min(видео, трек).
5. **Хранение готовых видео — ВАЖНО, изменено 27.08.2026:** готовые .mp4
   **не коммитятся** в репозиторий (иначе он растёт на ~150–200 МБ в день).
   Только присылаются пользователю в чат (`SendUserFile`, статус `proactive`,
   разумными партиями). В git коммитится только обновлённый `progress.md`
   (и скрипты, если менялись).
5a. **Куда слать — ВАЖНО, уточнено 28.08.2026:** только в чат текущей
   персистентной сессии (`session_01PQ3rQdapSdSAdCw9D2W6Ex`, к ней привязан
   триггер через `persistent_session_id`) — **никогда** не создавать новую/
   скрытую сессию для прогона (`create_new_session_on_fire` не использовать).
   Если по какой-то причине триггер снова создаёт отдельную сессию —
   это ошибка конфигурации, нужно пересоздать триггер с `persistent_session_id`
   на эту же сессию.
6. Если что-то в партии не получилось (битое фото, нет аудио и т.п.) — не
   останавливать всю партию, пропустить эту пару, отметить в логе ниже,
   продолжить остальные.
7. В конце — обновить этот файл: указатель на следующую свободную пару,
   дата прогона, что было сгенерировано, какие циклы (хуки/фото) обернулись.

Если пользователь попросит остановить автозапуск — удалить триггер и
убрать этот раздел.

## Следующая пара для новых видео

Следующий свободный номер: **54**. С этой пары фото-пул расширен до 56 (добавлены
IMG_4013–4032) — цикл по фото **перезапускается заново** с пары 54, чтобы
все 20 новых фото гарантированно попали в дело, а не ждали, пока естественным
образом дойдёт очередь по старой mod-36 арифметике:

**позиция_фото(N) = ((N − 54) mod 56) + 1**, где N — номер пары, позиция —
порядковый номер в отсортированном списке всех `IMG_*.jpeg` (1=IMG_3790.jpeg,
..., 56=IMG_4032.jpeg).

Пара 54 → фото IMG_3790.jpeg (позиция 1) + хук №54 «Как перестать откладывать
подготовку к ЕГЭ на завтра».

Если попросят «сделай ещё N видео» — брать пары №54, №55, ... по порядку,
фото — по формуле выше (полный круг из 56 каждые 56 пар), хуки берутся по
порядку (сначала ХУКИ.pdf 1–100, затем 101–200, затем по кругу с №1 — см.
раздел «Автоматизация» выше), и по умолчанию накладывается музыка так же,
как описано выше.
