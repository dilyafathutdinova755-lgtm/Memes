## Музыка (с видео 14)

С видео 1–13 родной звук ролика (тишина 0–6с + звук приложения 6–15с) не менялся.
Начиная с видео 14 пользователь прислал 5 аудиодорожек (`output/audio/track1..5.m4a`,
извлечены из присланных скринкастов). Правило наложения:

- Аудио полностью заменяет родной звук ролика, громкость 100% (без подмешивания).
- Трек на каждое видео выбирается случайно из 5 (повторы допускаются).
- Итоговая длительность ролика = **min(15.02с видео, длительность трека)**:
  - трек короче — обрезается по нему конец видео (аутро укорачивается)
  - трек длиннее — обрезается сам трек до длины видео

Длительности треков: track1=13.93с, track2=14.30с, track3=14.51с, track4=14.90с, track5=16.13с.

Для новых видео (с №24) нужно повторить это же наложение музыки, если пользователь
не скажет иначе — треки уже лежат в `output/audio/`.
