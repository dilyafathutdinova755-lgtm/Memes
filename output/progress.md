затем 101–200), без повторов, по порядку — пока не кончатся все 200 (тогда по кругу).

заканчиваются, список идёт по кругу.

## Музыка (с видео 14, правило постоянное)

Пользователь прислал 5 аудиодорожек (извлечены из скринкастов, лежат в
`output/audio/track1..5.m4a`, AAC 44.1kHz stereo). Правило действует для
всех видео начиная с №14 и **остаётся в силе для всех будущих партий**,
пока не будет сказано иначе:

- На каждое видео случайно (с повторами) выбирается один из 5 треков.
- Трек **полностью заменяет** родной звук ролика (100% громкость, без подмешивания).
- Итоговая длительность ролика = **min(длительность видео ~15.02с, длительность трека)**:
  - трек короче видео → обрезается видео (конец аутро укорачивается)
  - трек длиннее видео → обрезается сам трек

Длительности треков: track1=13.93с, track2=14.30с, track3=14.51с, track4=14.90с, track5=16.13с.

## Автоматизация: ежедневная генерация в 7:00 (Europe/Moscow)

С 27.08.2026 настроен ежедневный автозапуск (cron `0 4 * * *` UTC = 7:00 МСК),
каждый день генерирует **40 новых видео** без участия пользователя. Правила
для автономного прогона:

1. **Пары (фото+хук):** брать следующие 40 свободных номеров подряд от
   текущего указателя ниже.
2. **Хуки:** ХУКИ.pdf (1–100) + `100 хуков ЕГЭ Тренажёр 101-200.pdf` (101–200)
   + `100 хуков родители 201-300.pdf` (201–300, добавлен 02.09.2026 — хуки
   от лица **родителя одиннадцатиклассника**, не самого ученика; см. пункт 8
   ниже — для них отдельное правило доставки). Итого пул — **300 хуков**.
   **Когда все доступные хуки заканчиваются — начинать заново с хука №1**
   (по кругу), а не останавливаться. Пара «фото+хук» всё равно уникальна по
   номеру, даже если и фото, и хук в моменте повторяются.
   **02.09.2026:** когда добавили хуки 201–300, шла вторая проходка по кругу
   1–200 (дошли до исходного хука №93 на паре 293). Свежие 201–300 ни разу
   не использовались — по правилу «не повторяться, пока не кончатся все»
   им отдан приоритет: со следующей пары (294) идём по хукам 201, 202, ...
   300 подряд (пары 294–393), а недопройденный второй круг 1–200
   прерывается. После хука 300 (пара 393) цикл **перезапускается заново с
   хука №1** по всему пулу из 300 (упрощение — не пытаемся точно возобновить
   прерванный второй круг с того места, где остановились).
3. **Фото:** по кругу из отсортированного списка `IMG_*.jpeg` в корне репо.
   С пары 294 пул — **72 фото** (добавлены IMG_4573 и далее 02.09.2026,
   плюс обновлено содержимое IMG_3904.jpeg/IMG_3906.jpeg — те же имена файлов,
   но новая картинка). Цикл перезапущен заново с пары 294 (как и с хуками),
   чтобы новые фото гарантированно попали в дело:
   **позиция_фото(N) = ((N − 294) mod 72) + 1** (1=IMG_3790.jpeg, ..., 72=IMG_4590.jpeg
   по отсортированному списку). Если добавят ещё фото — повторить тот же
   приём: перезапустить цикл с новым модулем на паре добавления.
4. **Музыка:** правило то же, что и раньше (см. раздел выше) — трек случайно
   из `output/audio/track*.m4a` (включая любые новые, если добавлены),

   постоянное:** перед упаковкой в архивы проверять текст каждого хука на

   «перестала», «подготовилась», «начала», «сказала», «забывала»,
   «подтянула» и т.п. — субъект действия сам говорящий, а не согласование
   с посторонним существительным вроде «теория ... запоминалась»).
   - Видео с такими хуками — **отдельная группа архивов** («женский род»).

     («без рода»).

     не смешивать в одном архиве.
