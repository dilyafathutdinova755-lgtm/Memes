## Музыка (с видео 14, правило постоянное)

Пользователь прислал 5 аудиодорожек (извлечены из скринкастов, лежат в
`output/audio/track1..5.m4a`, AAC 44.1kHz stereo). Правило действует для
всех видео начиная с №14 и **остаётся в силе для всех будущих партий**,
пока не будет сказано иначе:

- На каждое видео случайно (с повторами) выбирается один из 5 треков.
- Трек **полностью заменяет** родной звук ролика (100% громкость, без подмешивания).
- Итоговая длительность ролика = **min(длительность видео ~15.02с, длительность трека)**:
  - трек короче видео → обрезается видео (конец аутро укорачивается)
  - трек длиннее видео → обрезается сам трек

Длительности треков: track1=13.93с, track2=14.30с, track3=14.51с, track4=14.90с, track5=16.13с.

## Автоматизация: ежедневная генерация в 7:00 (Europe/Moscow)

С 27.08.2026 настроен ежедневный автозапуск (cron `0 4 * * *` UTC = 7:00 МСК),
каждый день генерирует **40 новых видео** без участия пользователя. Правила
для автономного прогона:

1. **Количество и разбивка на потоки — ВАЖНО, ИЗМЕНЕНО 02.09.2026 (было 40/день
   единым потоком, по прямой просьбе пользователя):** каждый день теперь
   генерируется **58 видео**, двумя независимыми потоками с отдельными
   циклами хуков (см. пункт 2):
   - **Поток 1a («основной»), 40 видео/день:** хуки только из
     **студенческого пула (1–200)**. Пары нумеруются следующими свободными
     номерами подряд от общего указателя, как и раньше.
   - **Поток 1b («родительская квота»), 18 видео/день:** хуки только из
     **родительского пула (201–400)**. Пользователь явно потребовала
     фиксированное количество: ровно **4 архива «РОДИТЕЛИ ЖЕН РОД» (12
     видео)** + **2 архива «РОДИТЕЛИ МУЖ РОД» (6 видео)** каждый день —
     это НЕ часть общего смешанного цикла, а гарантированная ежедневная
     квота. **ВАЖНО, уточнено 02.09.2026 (второй раз в этот же день):**
     если специфично-гендерных (женских/мужских) хуков в родительском пуле
     в моменте не хватает — добирать нужное количество видео хуками **без
     рода** из родительского пула, и класть их **прямо в те же архивы
     «РОДИТЕЛИ ЖЕН РОД» / «РОДИТЕЛИ МУЖ РОД»**, в зависимости от того, какой
     квоте не хватает видео. **Отдельной категории/архива «РОДИТЕЛИ БЕЗ
     РОДА» больше нет** — это было первое решение в течение дня 02.09.2026,
     пользователь его отменила и явно попросила не выделять для этого
     отдельную папку/зип, а просто добавлять такие видео в гендерные архивы.
     При нормальном ходе дел гендерных хуков должно хватать, т.к. в пуле
     201–400 их подавляющее большинство — фолбэк без рода нужен редко.
     Подробный алгоритм отбора — см. пункт 8.
   Оба потока используют общий сквозной номер пары (58 новых номеров за
